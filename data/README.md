# Données à télécharger

Télécharger les fichiers depuis [la compétition Kaggle](https://www.kaggle.com/competitions/store-sales-time-series-forecasting/data), puis placer ici les cinq CSV suivants :

- `train.csv`
- `test.csv`
- `sample_submission.csv`
- `holidays_events.csv`
- `stores.csv`

Le notebook utilise uniquement ces fichiers. `oil.csv` et `transactions.csv` ne sont pas utilisés. Les données brutes ne sont pas incluses dans le dépôt.
